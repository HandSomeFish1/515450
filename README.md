# 515450 红利低波 · 综合温度计 + 日投策略

两件事：**每天一秒算出温度分**，以及**按温度分决定今天投多少钱**（已用基金成立以来的数据回测）。

## 每天怎么用

双击 **`每日打分.cmd`**（就这一个动作）：

1. 自动抓行情、股息率、10 年国债收益率；
2. 算出温度分，生成 `report.html` 并打开浏览器；
3. 同步一份 `515450温度计.html` 到桌面；
4. 把当天结果追加进 `history.csv`（同一天重复运行只保留最后一次）。

报告里会直接显示**今天该投多少**，以及**定投账本**（累计投入、市值、浮盈、XIRR）。

账本按规则逐日回放：从 `config.json` 里的 `dca.ledger_start`（当前 2026-10-19）到今天，
**缺跑的日子会自动补算**，所以不用每天准点双击也不会漏记录。

你前几天的真实记录已经按「每天固定 100 元」写进账本（`actual_amount`），
从 `rule_from`（2026-10-26，下个交易日）起改成按温度分规则自动记账。
如果打算一直固定投 100，把 `rule_from` 删掉即可。

## 定投规则（成立以来回测出来的相对最优）

```
当天投入 = 100 + (50 − 温度分) × 8   元
          分数 ≥ 50 → 100 元（下限）
          分数 ≤ 0  → 500 元（上限）
          取整到 10 元
```

| 温度分 | 当天投 |
| --- | --- |
| ≤ 0 | 500 元 |
| 10 | 420 元 |
| 20 | 340 元 |
| 35 | 220 元 |
| 50 及以上 | 100 元 |

- **频率：每个交易日买一笔**，每笔 100–500 元。分数越低买得越多，分数越高买得越少（但不会停买）。
- 等价于 `config.json` 里的锚点 `0 → 500 / 50 → 100`。
- **支付宝 0.12% 申购费已计入**（外扣法：份额 = 金额 ÷ 1.0012 ÷ 净值），账本里有「累计手续费」一栏。

## 打分口径（与原网页一致）

```
综合分 = 利差分位×35 + 股息率×25 + RSI14×20 + 年线BIAS×10 + 市场情绪×10
```

0–20 极度低估（重仓） / 21–40 偏冷（建仓） / 41–60 中性（观望） / 61–80 偏热（止盈） / 81–100 极度高估（清仓）

## 谷底分（报告里第二张卡片）

温度分是“绝对估值水平”，牛市里容易贴边。谷底分是给同一只基金设计的**相对起伏**指标：

```
便宜度 = 0.60 × 回撤深度（距一年高点跌幅 ÷ 15%，封顶 100）
       + 0.25 × 三年位置（价格在近三年区间的位置取反）
       + 0.15 × 利差位置（股息率 − 10Y 的三年分位）

谷底分 = 便宜度在过去 750 个交易日里的分位（0–100）
```

0–20 顶部区 / 20–40 偏热 / 40–60 中性 / 60–80 偏冷 / **80–100 谷底区**

回测（2023-03 ~ 2026-10，875 个交易日）：后 60 日 Spearman +0.43，穿 50 分线 90 次；
80–100 档 116 天，后 60 日平均 +7.50%、正收益占比 96%。

> 注意：谷底分只覆盖 2023-03 之后（需要 750 个交易日的滚动窗口），且它和温度分是两个视角——
> 温度分回答“历史上贵不贵”，谷底分回答“相对最近三年跌得够不够深”。

### 数据来源

- 回测价格：天天基金 `pingzhongdata` 的 515450 成立以来净值，用「单位净值 + 分红再投资」还原复权净值
- 沪深300、实时行情：腾讯证券日线
- 股息率、PE、PE 历史分位：蛋卷基金指数估值（中证红利低波 CSIH30269）
- 中国 10 年期国债收益率：东方财富数据中心

### 近似口径（报告里也写明了）

1. **利差分位**：用「股息率 − 10 年国债」当前值，在近 10 年约 500 个周度样本里排名换算，
   0% = 利差历史最大 = 最便宜。历史股息率用「当前股息率 × 当前 PE ÷ 历史 PE」估算。
2. **市场情绪**：用 515450 相对沪深300 的 60 日超额收益映射成 0–100（跑输=被抽血=低分），
   不是真实资金流数据。
3. 回测用复权净值算信号，每日报告用场内价格算信号，两者偶尔差 1–2 分。

## 回测的局限

- **日投很吃资金**：全区间累计投了 31.8 万，平均每年约 5.6 万，先确认现金流撑得住再执行。
- 全区间看，温度分加码相对等额日投只多约 0.5 个百分点/年；优势主要在回撤控制和 2024/2026 这类行情里，别指望它把收益翻倍。
- 2022 年几乎不赚钱（XIRR +0.37%），2021 和 2024 很赚 —— 收益高度集中在少数年份。
- 温度分里的股息率、PE 分位由蛋卷周度估值插值估算，存在口径误差；回测已计 0.12% 申购费，未计卖出佣金与跟踪误差。
- 每日报告里的账本是「按规则回放」，不是券商真实持仓；要记真实成交，需要自己把 `config.json` 的 `ledger_start` 改成实际开始日期。

## 想改点东西

- 换权重 / 阈值 / 定投锚点 / 金额上下限 / 桌面副本位置：改 `config.json`，下一次运行生效。
- 换定投频率（周/月）：`strategy_lab.py` 里把 `sim()` 循环改成隔 N 个交易日即可。
- 改样式：改两个 `*_template.html`。

## 出问题怎么办

- **运行很慢/像卡住**：正常 8–10 秒。开跑后会有 5 行进度（取日线 → 沪深300 → 估值 → 国债 → 净值），
  只要在动就没卡；整体有 90 秒硬时限，超时会直接报错退出，旧报告不会被覆盖。
- **用哪天的数据**：工作日 9:30–11:30、13:00–15:00 运行 → 用**当时的价格**算温度，标题显示「即时 2026-10-26 10:23」；
  其余时间（开盘前、午休、收盘后、周末、节假日）→ 自动退到**最近一个已收盘交易日**，标题显示「数据日 …（最近收盘日）」。
  想强制随时都用最新一根 K 线，把 `config.json` 的 `use_intraday` 改成 `true`。
- 窗口一闪就看报错：在该目录的命令行里运行 `每日打分.cmd`，报错会留在窗口里。
- 数据抓取失败：脚本重试 3 次后退出并打印原因，不会写半截报告，也不会污染 `history.csv`。
- 想拿当日收盘价：15:00 收盘后再跑。
- 桌面副本写不进去（权限/占用）：报告仍会生成并打开，只是不复制。
